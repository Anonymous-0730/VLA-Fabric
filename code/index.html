Analyze communication profiles

python analysis.py profiles
python analysis.py profiles --reference Full --candidate NSPR-8

Reports traffic and critical-path reductions against the selected reference, and success changes in percentage points.

Compare paired outcomes

python analysis.py paired reference.csv candidate.csv

Each CSV contains condition_id and binary success. The utility checks that conditions match before constructing the paired outcome counts.

Reproduce the cross-task figure

python plot_results.py --output cross-task.pdf

Success uses paired-200 evaluations. Timing uses separate strict timing-50 runs. Source values and measurement definitions accompany the results.

This release includes communication-analysis and evaluation utilities. Additional implementation components will be released progressively.
