The idea

From a fixed policy to a network of agents.

What if adding an arm meant connecting another complete VLA policy? VLA-Fabric makes communication between action-producing policies an explicit systems interface, while preserving each arm's local observations and actions.

Compose complete agents

Each arm keeps a complete VLA policy. Teams grow by adding agents, without expanding the local action space.

Make coordination explicit

Three representation-level communication paths connect agents across process and device boundaries.

Communicate efficiently

Compact representations and behavior-aware layer screening reduce communication while retaining task capability.

Architecture

Local control. Shared coordination.

Every agent observes and acts locally. Instead of sharing raw observation streams or predicting a joint action, agents exchange intermediate representations at three points in the policy.

Common

Shared task and scene context, synchronized within the transformer stack.

Private K/V

Peer-specific context for local attention. Each agent's query stays local.

Action intent

Late-stage peer information before each agent decodes its own action.

The same organization supports centralized training and process- and device-isolated inference. Team-size-specific training is still required; a fixed team can learn multiple tasks.

Communication efficiency

Keep the coordination. Reduce the exchange.

Making communication explicit exposes a new cost. VLA-Fabric reduces both representation redundancy and synchronization frequency, with closed-loop task behavior guiding which exchanges to retain.

Raw

The direct operator-level interface exposes the original common-path dependencies across devices.

Full

A layer-boundary hidden workspace replaces repeated intermediate exchanges while keeping all layers active.

NSPR-8

Behavior-aware screening retains eight synchronization layers. Private K/V and Action remain enabled.

Which synchronization layers matter?

The next-synchronization post-residual (NSPR) measures whether a perturbation survives the next opportunity for synchronization. Combined with action-level metrics, it nominates candidate layers for removal; paired closed-loop evaluation determines whether a removal is accepted.
